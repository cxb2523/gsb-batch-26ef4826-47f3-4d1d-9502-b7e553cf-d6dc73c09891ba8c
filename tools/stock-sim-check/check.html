Stock simulation consistency check

Loads the viewer's own scripts and the sample G-code, then checks that the carved stock depends only on the hidden tools, earlier jobs and the animation position. It also checks that rebuilding the simulator releases its GPU buffers. Open this file directly in a browser, or serve the repository (for example python -m http.server) and open tools/stock-sim-check/check.html if the browser blocks the G-code fetch from a file:// page.
